# Dummy Login Form

This is my **first Login Form project**, created as a beginner-level web development project to practice the basics of **HTML and CSS**.

The project focuses on creating a simple and clean login interface where users can enter their username/email and password. It helped me understand how to structure a webpage, create form elements, and style them using CSS.

## 🚀 Features

* Simple and clean login form design
* Username/Email input field
* Password input field
* Login button
* Basic CSS styling
* Beginner-friendly HTML structure
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the login form.
* **CSS3** – Used to style and design the login page.

## 📚 What I Learned

While creating this project, I learned and practiced:

* Creating HTML forms
* Using input fields
* Using labels and buttons
* Structuring HTML documents
* Applying CSS properties
* Working with margins, padding, borders, and colors
* Creating a simple user interface
* Organizing files for a web project

## 🎯 Purpose of the Project

The main purpose of this project is to improve my fundamental web development skills. Since this is my first login form, it is a practice project and does not include a real authentication system or database connection.
