# Dummy Login Form

This is my **first Login Form project**, created as a beginner-level web development project to practice the basics of **HTML and CSS**.

The project focuses on creating a simple and clean login interface where users can enter their username/email and password. It helped me understand how to structure a webpage, create form elements, and style them using CSS.

## 🚀 Features

* Simple and clean login form design
* Username/Email input field
* Password input field
* Login button
* Basic CSS styling
* Beginner-friendly HTML structure
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the login form.
* **CSS3** – Used to style and design the login page.

## ⚙️ Setup

Follow these steps to run the project on your computer:

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/your-username/Dummy-login-form.git
```

Replace `your-username` with your actual GitHub username.

### 2. Open the Project Folder

Navigate to the project directory:

```bash
cd Dummy-login-form
```

### 3. Open the Project

You can open the `index.html` file directly in your web browser.

Alternatively, if you are using **Visual Studio Code**, you can open the project folder and use the **Live Server** extension to launch the webpage.

## ▶️ Usage

Once the project is opened in your browser:

1. Enter a username or email in the username/email field.
2. Enter a password in the password field.
3. Click the **Login** button.
4. Since this is a dummy login form, the form does not perform real authentication.

The project is currently intended for **learning and practice purposes**.
